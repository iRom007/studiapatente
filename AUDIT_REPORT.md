## КРИТИЧЕСКИЕ БАГИ (P1)

### BUG-01 · Тема НЕ синхронизируется между страницами
- **Файл:** index.html + category-b.html
- **Код:** `localStorage.setItem('sp_theme', ...)` (index) vs `localStorage.setItem('theme', ...)` (category-b)
- **Описание:** Ключи хранения темы разные в двух файлах. Пользователь переключает тему на главной — в квизе тема сбрасывается на дефолтную dark. И наоборот.
- **Влияние:** Тема сбрасывается при каждом переходе между страницами. UX сломан.
- **Приоритет:** P1 — КРИТИЧНО
- **Фикс:** Унифицировать ключ → использовать `'theme'` везде. В index.html заменить `'sp_theme'` → `'theme'` в `toggleTheme()` и INIT.

---

### BUG-02 · Размер шрифта НЕ синхронизируется между страницами
- **Файл:** index.html + category-b.html
- **Код:** `localStorage.setItem('sp_font', fontIdx)` (index) vs `localStorage.setItem('fontLg', isLg ? '1' : '0')` (category-b)
- **Описание:** Разные ключи, разная логика (index: 3 уровня 16/18/20px; category-b: бинарный флаг normal/lg).
- **Влияние:** Настройки шрифта не сохраняются между страницами. Частично несовместимый UX.
- **Приоритет:** P1 — КРИТИЧНО
- **Фикс:** Унифицировать на единый ключ `'fontLg'` с бинарной логикой, или переработать оба в трёхступенчатый режим с ключом `'sp_font'`.

---

### BUG-03 · FOUC (Flash of Unstyled Content) — тема применяется поздно
- **Файл:** category-b.html (строка ~2878525 из 2883530 — 99.1% файла)
- **Код:** `(function() { const saved = localStorage.getItem('theme'); ... })()` — выполняется в конце `<body>` после всего контента
- **Описание:** Тема читается из localStorage только в конце страницы. При загрузке HTML-тег уже имеет `data-theme="dark"` хардкодом, что вызывает мигание при светлой теме.
- **Влияние:** Пользователи со светлой темой видят вспышку тёмного фона (~100–300ms) при каждой загрузке.
- **Приоритет:** P1
- **Фикс:** Перенести блок восстановления темы в `<head>` внутри `<script>`:
  ```html
  <head>
    ...
    <script>
      (function(){
        try {
          const t = localStorage.getItem('theme');
          if (t) document.documentElement.setAttribute('data-theme', t);
        } catch(e) {}
      })();
    </script>
  </head>
  ```
  То же самое применить к index.html.

### BUG-04 · TEST MODE в продакшн коде — лимиты отключены
- **Файл:** category-b.html (~строка 1590–1640)
- **Код:**
  ```js
  function canAskQuestion() {
    return true; // TEST MODE
    return getUsage().questions < FREE_DAILY;
  }
  function canStartExam() {
    return true; // TEST MODE
    return getUsage().exams < FREE_EXAMS;
  }
  let isPremium = true;
  function checkRenewal() {
    isPremium = true; // TEST MODE — always premium
    ...
  }
  ```
- **Описание:** Все ограничения Free tier и Premium-пейвол полностью обойдены TEST MODE-флагами. Монетизация не работает.
- **Влияние:** Приложение не зарабатывает деньги. Все пользователи имеют бесплатный Premium.
- **Приоритет:** P1 — блокирует монетизацию
- **Фикс:** Убрать `return true; // TEST MODE` и `isPremium = true;`. Реализовать checkRenewal() с реальной проверкой `premium_expiry` из localStorage.

## СЕРЬЁЗНЫЕ БАГИ (P2)

### BUG-05 · Ключ языка — двойной стандарт
- **Файл:** index.html
- **Код:** Пишет `localStorage.setItem('sp_home_lang', l)`, читает `localStorage.getItem('lang') || localStorage.getItem('sp_home_lang')`
- **Описание:** index.html пишет `sp_home_lang`, но читает `lang` первым — это ключ от category-b.html. При первом визите на главную после квиза — язык корректно подхватывается из `lang`. Но при первом визите вообще — пишется `sp_home_lang`, который никогда не прочитается первым.
- **Влияние:** Непоследовательное сохранение языка. При определённых сценариях язык не сохраняется.
- **Приоритет:** P2
- **Фикс:** Унифицировать на `'lang'` везде. В index.html заменить `'sp_home_lang'` → `'lang'`.

---

### BUG-06 · `lang` атрибут HTML не меняется динамически в category-b.html
- **Файл:** category-b.html, INIT-секция
- **Код:** `<html lang="ru" ...>` хардкодом; в setLang() не обновляется `document.documentElement.lang`
- **Описание:** Атрибут `lang` страницы всегда `ru` независимо от выбранного языка. Критично для скринридеров и поисковых систем.
- **Влияние:** SEO, Accessibility (WCAG 3.1.1)
- **Приоритет:** P2
- **Фикс:** В `setLang()` добавить: `document.documentElement.lang = lang;`

---

### BUG-07 · Хардкоденный русский текст вне системы переводов
- **Файл:** category-b.html
- **Код:** 
  - `bannerEl.textContent = \`осталось ${remaining}\`` (updateDailyUI)
  - `btn.textContent = isLg ? 'Аа▲' : 'Аа'` (toggleFont)
  - `alt="Рисунок к вопросу"` (img alt)
- **Описание:** Три строки захардкоданы по-русски и не переводятся при смене языка.
- **Влияние:** Пользователи IT/EN видят русский текст в интерфейсе.
- **Приоритет:** P2
- **Фикс:** Добавить эти строки в систему переводов applyI18n / LANGS-объект.

---

### BUG-08 · Emoji 🌙/☀️ в theme-btn category-b.html (разный размер)
- **Файл:** category-b.html
- **Код:** `document.getElementById('theme-btn').textContent = isDark ? '🌙' : '☀️';`
- **Описание:** Emoji-иконки рендерятся крупнее текстовых символов. В index.html уже исправлено (☾/☀), в category-b.html — нет.
- **Влияние:** Визуальный баг — кнопка темы большего размера чем кнопки языков.
- **Приоритет:** P2
- **Фикс:** Заменить `'🌙'` → `'☾'` и `'☀️'` → `'☀'` в toggleTheme() и в блоке восстановления темы category-b.html.

---

### BUG-09 · Экзамен без таймера — несоответствие реальному экзамену
- **Файл:** category-b.html, startExam()
- **Код:** `beginSession(qs, examTitle)` — нет таймера обратного отсчёта
- **Описание:** Реальный итальянский экзамен даётся 30 минут на 30 вопросов. В симуляции таймера нет совсем.
- **Влияние:** Пользователь не готовится к реальному регламенту экзамена.
- **Приоритет:** P2
- **Фикс:** Добавить таймер 1800 секунд (30 мин) с отображением оставшегося времени, автозавершением по истечении, и предупреждением при <5 минутах.

## SEO ПРОБЛЕМЫ (P2–P3)

### SEO-01 · Нет Open Graph тегов — ни в одном файле
- **Файл:** index.html, category-b.html
- **Влияние:** Ссылки в Telegram/WhatsApp/социальных сетях показываются без превью (нет og:title, og:description, og:image).
- **Приоритет:** P2
- **Фикс:** Добавить в `<head>` каждой страницы:
  ```html
  <meta property="og:title" content="StudiaPatente — Подготовка к итальянским правам">
  <meta property="og:description" content="6832 вопроса официальной базы MIT. Категории A1, A2, A, B.">
  <meta property="og:type" content="website">
  <meta property="og:url" content="https://irom007.github.io/studiapatente/">
  ```

### SEO-02 · Нет мета description в category-b.html
- **Влияние:** Google показывает произвольный отрывок вместо описания.
- **Фикс:** Добавить `<meta name="description" content="...">`.

### SEO-03 · Нет canonical URL ни в одном файле
- **Влияние:** Дублирование контента при разных URL (http vs https, с/без www, с/без trailing slash).
- **Фикс:** Добавить `<link rel="canonical" href="https://studiapatente.it/...">`.

### SEO-04 · Нет robots.txt и sitemap.xml
- **Влияние:** Поисковики могут не индексировать страницы оптимально.
- **Фикс:** Создать `/robots.txt` и `/sitemap.xml`.

### SEO-05 · Нет favicon и apple-touch-icon
- **Влияние:** Браузер показывает пустую иконку. При добавлении на HomeScreen нет иконки приложения.
- **Фикс:** Создать favicon.ico, favicon-32.png, apple-touch-icon-180.png.

### SEO-06 · Нет структурированных данных (JSON-LD)
- **Влияние:** Нет шанса на Rich Snippets в поиске.
- **Фикс:** Добавить `@type: "WebApplication"` или `"EducationalOrganization"` JSON-LD.

### SEO-07 · `<html lang="ru">` хардкодом — не меняется при смене языка
- **Влияние:** Поисковики видят страницу только как русскую, даже при IT/EN интерфейсе.
- **Фикс:** Обновлять через JS при смене языка + использовать hreflang теги.

## UX ПРОБЛЕМЫ (P3)

### UX-01 · privacy.html и support.html — нет переключателя языка
- **Файл:** privacy.html, support.html
- **Описание:** Страницы только на русском, нет lang-switcher в навигации.
- **Влияние:** Итальянские и английские пользователи не понимают контент.
- **Приоритет:** P3
- **Фикс:** Добавить минимальный lang-switcher + переводы для заголовков и основного текста.

### UX-02 · Нет мета description в category-b.html (ещё и UX-проблема SEO)
(совпадает с SEO-02)

### UX-03 · Один mobile breakpoint (480px) — нет 768px для планшетов
- **Файл:** category-b.html, index.html
- **Описание:** Медиа-запрос только `@media (max-width: 480px)`. На планшетах (768px) layout не адаптирован.
- **Влияние:** На iPad/планшете карточки тем отображаются в 2 колонки, но слишком мелко.
- **Приоритет:** P3
- **Фикс:** Добавить `@media (max-width: 768px)` с адаптацией grid и font-size.

### UX-04 · Нет swipe-навигации на мобильных
- **Описание:** В квизе нет поддержки swipe (touch events) для перехода между вопросами.
- **Влияние:** На мобильных неудобно — только кнопки.
- **Приоритет:** P3
- **Фикс:** Добавить touchstart/touchend обработчик с определением направления свайпа.

### UX-05 · img alt="Рисунок к вопросу" только по-русски
(совпадает с BUG-07, но как отдельная accessibility-проблема)
- **Влияние:** Нарушает WCAG 1.1.1 для пользователей IT/EN со скринридером.

## ТЕХНИЧЕСКИЙ ДОЛГ (P4)

### TECH-01 · Весь JS (~2.8 MB) встроен в один HTML-файл
- **Файл:** category-b.html
- **Описание:** 2689 KB — данные вопросов, 101 KB — JS код. Всё в одном файле.
- **Влияние:** Первая загрузка ~4 MB. Невозможно кэшировать JS отдельно от данных. Сложно поддерживать.
- **Рекомендация:** Вынести QUESTIONS в отдельный `questions-b.json`, загружать через fetch(). Позволит кэшировать JS код отдельно.

### TECH-02 · 13 неиспользуемых PNG в img_sign/
- **Файл:** img_sign/ (913, 914, 934, 935, 962 и др.)
- **Описание:** 13 файлов присутствуют на диске, но не реферируются ни одним вопросом.
- **Влияние:** Незначительное увеличение репозитория.
- **Рекомендация:** Можно удалить или оставить — влияние минимально.

### TECH-03 · Отсутствует PWA manifest / service worker
- **Описание:** manifest.json ссылается в HTML, но файл не найден (или ссылка сломана в index.html).
- **Влияние:** Нет установки как PWA, нет offline-режима.
- **Рекомендация:** Создать manifest.json и базовый service worker.

### TECH-04 · Функция translateQ — покрытие ~87%
- **Описание:** 90 replace()-паттернов для RU/EN перевода вопросов. Нетипичные формулировки не переводятся.
- **Влияние:** ~13% вопросов остаются на итальянском при выбранном RU/EN.
- **Рекомендация:** Постепенно расширять паттерны translateQ. Долгосрочно — профессиональный перевод всех 6832 вопросов.
